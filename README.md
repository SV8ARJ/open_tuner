## SV8ARJ mods

### User-visible changes
- **Resizable BATC spectrum display:** The spectrum view can be resized with the application window and splitter; its image scales to fit, and the band-plan display scales with it.
- **Status-line transparency:** Adjust status-line transparency from the Settings dialog (0–90%). The setting is outside the UDP Streaming Settings panel and is saved with the other settings.
- **Status-line hover behavior:** Moving the mouse over a status line makes it fully opaque; moving away restores the selected transparency.
- **Automatic connection option:** A setting allows OpenTuner to connect automatically at startup.

# Open Tuner
Open Windows Software for use with DATV tuner variants based on the Minitiouner range.

## Main reasons for making these changes:
- An all-in-one solution for handling two TS streams (QSO full-duplex or supervision)
- More advanced software features compared to the abandoned and outdated MiniTioune software
- Support for VVC (Versatile Video Coding, H.266)

## Mainly tested device with this fork are:
- MiniTiouner Pro (with two USB ports)
- MiniTiouner V2 (Elad E-Tiouner, 1 USB port)
### Remark
Unfortunately, I don't have any other hardware, so I can't test it on a different device either.

For me, a beta release is a version that can be used by a broader group of users.

Key characteristics of a beta release:

✅ The main features have been implemented.
✅ The software is generally usable.
✅ Known and unknown issues are still to be expected.
✅ Users are encouraged to provide feedback and submit bug reports.
✅ Feature changes are kept to a minimum, with the focus shifting towards stabilization and bug fixing.
